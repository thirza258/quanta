# Original careful-investor worked cases

Attempt the lesson assignments before using these checks. Every company, household,
allocation and return here is fictional. The explanations are Quanta originals.

| Case | Calculation | Interpretation |
| --- | --- | --- |
| Liquidity pools | 120 − 30 − 24 = 66 million rupiah | Long-horizon capital after the stated case commitments |
| Loss scenario | 66 × 30% = 19.8 million | A capacity question, not a forecast |
| Purchasing power | 1.06 / 1.04 − 1 ≈ 1.923% | Exact real return under the assumptions |
| Fund overlap | 0.6 × 0.3 + 0.4 × 0.2 = 26% | Two wrappers can share one company exposure |
| Conservative cushion | 1 − 60/70 ≈ 14.29% | Lower than the base-case 40% margin |
| Case price ceiling | 70 × 0.75 = 52.5 | Applies only to the fictional 25%-cushion rule |
| Allocation stress | 0.6 × (−30%) + 0.4 × (−10%) = −22% | Stocks and bonds can both lose value |
| Allocation drift | 72/112 ≈ 64.286%; 72 − 112 × 0.6 = 4.8 | Transfer 4.8 before costs to restore 60/40 |
| Recurring earnings | (120 − 40)/20 = 4 EPS; 60/4 = 15 P/E | A one-time gain changes the headline multiple |
| Purchase averaging | 100/10 + 100/5 = 30 units; 200/30 ≈ 6.667 | Value at 5 is only 150 against 200 contributed |
| Promised compounding | 1.03^12 − 1 ≈ 42.58% | Arithmetic does not establish legitimacy |
| Scenario values | 0.6×100 + 0.4×50 = 80; 0.3×100 + 0.7×50 = 65 | Expectations are conditional, not guarantees |

For the twenty-year fee case, compute 10000×1.058^20 and 10000×1.045^20. The
stipulated 6% gross return and simplified fee subtraction are teaching assumptions.
Show this convention explicitly and avoid subtracting a reported net fee twice.
