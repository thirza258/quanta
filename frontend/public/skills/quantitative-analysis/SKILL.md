# Quantitative Analysis Skill

Use Quanta's financial analytics engine to analyze assets, run factor models, and backtest quantitative trading strategies.

## Capabilities

- Backtesting algorithmic trading strategies
- Portfolio optimization and risk modeling (VaR, CVaR, Sharpe ratio)
- Factor analysis and statistical arbitrage modeling
- Market data exploration and visualization

## Endpoints

- API Base: `https://quant.nevatal.id/api`
- OpenAPI Specification: `https://quant.nevatal.id/api/openapi.json`
- API Documentation: `https://quant.nevatal.id/api/docs`
